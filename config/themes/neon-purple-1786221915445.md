# Design System Specification: Neon Purple

> Official Design System Specification file (`design.md` standard). Synchronized with root CSS custom properties and WCAG 2.1 AA accessibility guidelines.

## 1. System Overview & Key Characteristics

- **Geometry Canvas Color**: `#190B15` (Deep Plum Violet).
- **Visual Philosophy**: Electric magenta highlights glowing against deep dark plum backdrops, creating a futuristic, high-contrast fintech aesthetic with glassmorphism overlays.
- **Contrast Strategy**: Dark mode default ensuring high readability ($>7:1$) for body copy and clear focus rings for interactive elements.

## 2. Color System & Design Tokens

| Token Key | Design System Role | Hex / CSS Value | Description |
| :--- | :--- | :--- | :--- |
| `primary_bg` | Primary Background | `#190B15` | Main application background (Deep Plum Violet) |
| `secondary_bg` | Secondary Background | `#12070F` | Inset section background & dark wells |
| `surface_card` | Surface Card | `#261220` | Elevated card containers & modal backdrops |
| `text_primary` | Primary Copy | `#F8FAFC` | High contrast white display headings & main copy |
| `text_secondary` | Secondary Copy | `#D6C2D0` | Soft plum-tinted slate subtitles & labels |
| `text_muted` | Muted Text | `#B398AB` | Captions, metadata, and fine print |
| `accent` | Accent Color | `#E718A9` | Signature neon magenta CTA & active highlights |
| `slate_steel` | Steel Slate | `#503046` | Muted borders, icon outlines, & secondary chips |
| `border_subtle` | Subtle Border | `rgba(255, 255, 255, 0.10)` | Card grid lines & translucent dividers |
| `border_accent` | Accent Border | `rgba(231, 24, 169, 0.25)` | Active state highlight focus borders |

### Color Categories & Variations

- **Brand & Accent**: Neon Magenta `#E718A9` (Accent) with Focus `#C0108A`. Used for CTAs, active pills, and status highlights.
- **Surface**: Plum Violet Canvas `#190B15`, Inset Well `#12070F`, Surface Card `#261220`.
- **Text Color Descriptions**: High-contrast white `#F8FAFC`, soft violet slate `#D6C2D0`, muted lavender `#B398AB`.
- **Semantics**: Magenta `#E718A9` (Accent/CTA), Rose `#F43F5E` (Error), Emerald `#10B981` (Success).

## 3. Hierarchy, Layout & Spacing System

- **Hierarchy**: Serif headings (Playfair Display) for editorial titles, clean sans-serif (Inter) for body copy, and monospaced font (Fira Code) for financial numbers.
- **Layout & Grid**: 12-column responsive fluid grid inside centered container (`max-w-7xl`).
- **Spacing Scale**: Linear 4px scale (`xs: 4px`, `sm: 8px`, `md: 16px`, `lg: 24px`, `xl: 32px`).
- **Whitespace Philosophy**: Generous margins around glowing neon elements to ensure focus and clarity.

## 4. Elevation, Depth & Shapes

- **Elevation & Depth**: Multi-layered dark surface cards with translucent glass backdrop filters.
- **Border Radius Scale**: `rounded-xs` (2px), `rounded-sm` (4px), `rounded-md` (8px), `rounded-lg` (12px), `rounded-full` (9999px).

## 5. Component Guidelines & Specifications

### Inputs & Forms
- **Form Select & Inputs**: `var(--color-surface)` background, `var(--border-subtle)` border, `var(--color-text-primary)` copy, `var(--border-accent)` focus ring.

### Cards & Containers
- **Surface Cards**: Glassmorphism translucent container (`bg-slate-900/60`) with 1px `var(--border-subtle)`.

### Navigation & Footer
- **Global Navigation Bar**: Fixed glass header with dynamic backdrop blur.
- **Footer**: Integrated multi-column footer displaying platform links and legal information.

## 6. Do's and Don'ts

### Do's
- **Do**: Bind all element styles to CSS custom property tokens.
- **Do**: Maintain WCAG AA compliance across text contrast ratios.

### Don'ts
- **Don't**: Never use static color values without CSS custom properties.
- **Don't**: Never use `!important` overrides in stylesheets.
