# Design System Specification: lemon

> Official Design System Specification file (`design.md` standard). Synchronized with root CSS custom properties and WCAG 2.1 AA accessibility guidelines.

## 1. System Overview & Key Characteristics

- **Geometry Canvas Color**: `#14190B` (Deep Electric Moss Charcoal).
- **Visual Philosophy**: Electric high-energy neon lime highlights against organic dark olive-charcoal backdrops, providing striking contrast for active UI metrics and interactive controls.
- **Contrast Strategy**: High-luminance accent `#9FF500` ensures maximum visibility for CTAs and status badges while maintaining WCAG 2.1 AA compliance.

## 2. Color System & Design Tokens

| Token Key | Design System Role | Hex / CSS Value | Description |
| :--- | :--- | :--- | :--- |
| `primary_bg` | Primary Background | `#14190B` | Main application background (Moss Charcoal) |
| `secondary_bg` | Secondary Background | `#0E1207` | Deep section backdrop & inset wells |
| `surface_card` | Surface Card | `#1F2612` | Elevated card containers & modal surfaces |
| `text_primary` | Primary Copy | `#F8FAFC` | High contrast white headlines & main copy |
| `text_secondary` | Secondary Copy | `#CFD6C2` | Soft lime-tinted slate subtitles & labels |
| `text_muted` | Muted Text | `#AAB398` | Captions, metadata, and fine print |
| `accent` | Accent Color | `#9FF500` | Signature electric lemon CTA & active highlights |
| `slate_steel` | Steel Slate | `#455030` | Muted borders, icon outlines, & secondary chips |
| `border_subtle` | Subtle Border | `rgba(255, 255, 255, 0.10)` | Card grid lines & translucent dividers |
| `border_accent` | Accent Border | `rgba(159, 245, 0, 0.25)` | Active state highlight focus borders |

### Color Categories & Variations

- **Brand & Accent**: Electric Lime `#9FF500` (Accent) with Focus `#84CC00`. High-visibility CTA button fill with dark text on primary button state.
- **Surface**: Moss Charcoal Canvas `#14190B`, Deep Well `#0E1207`, Card Surface `#1F2612`.
- **Text Color Descriptions**: High-contrast white `#F8FAFC`, lime-gray `#CFD6C2`, muted olive `#AAB398`.
- **Semantics**: Electric Lemon `#9FF500` (Success/Accent), Crimson `#F43F5E` (Error), Amber `#F59E0B` (Warning).

## 3. Hierarchy, Layout & Spacing System

- **Hierarchy**: Display headings in Playfair Display serif font, balanced by clean Inter body text and monospaced code elements.
- **Layout & Grid**: Standard 12-column grid layout inside centered container (`max-w-7xl`).
- **Spacing System**: Consistent 4px linear grid (`xs: 4px`, `sm: 8px`, `md: 16px`, `lg: 24px`, `xl: 32px`).
- **Whitespace Philosophy**: Crisp, focused margins highlighting glowing active components.

## 4. Elevation, Depth & Shapes

- **Elevation & Depth**: Multi-layered dark surface cards with subtle border outlines and soft radial glows.
- **Border Radius Scale**: `rounded-xs` (2px), `rounded-sm` (4px), `rounded-md` (8px), `rounded-lg` (12px), `rounded-full` (9999px).

## 5. Component Guidelines & Specifications

### Inputs & Forms
- **Select & Text Inputs**: Background set to `var(--color-surface)`, text color `var(--color-text-primary)`, focus ring `var(--border-accent)`.

### Cards & Containers
- **Card Containers**: `var(--color-surface)` with `var(--border-subtle)` hair lines.

### Navigation & Footer
- **Global Header**: Fixed top navigation bar with dynamic backdrop blur.
- **Footer**: Integrated multi-column footer displaying site links and credits.

## 6. Do's and Don'ts

### Do's
- **Do**: Pair electric lime `#9FF500` with dark text (`#0E1207`) when used as a button background.
- **Do**: Ensure all interactive controls consume root CSS variables.

### Don'ts
- **Don't**: Never use low-contrast text on bright lime surfaces.
- **Don't**: Never bypass CSS variable tokens with hardcoded color utilities.
