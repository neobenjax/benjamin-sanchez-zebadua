# Design System Specification: Apple-design-system

> Official Design System Specification file (`design.md` standard). Synchronized with root CSS custom properties and WCAG 2.1 AA accessibility guidelines.

## 1. Color System & Design Tokens

| Token Key | Design System Role | Hex / CSS Value | Description |
| :--- | :--- | :--- | :--- |
| `primary_bg` | Primary Background | `#ffffff` | Main application background (Pure White canvas) |
| `secondary_bg` | Secondary Background | `#f5f5f7` | Alternating section backdrops (Parchment) |
| `surface_card` | Surface Card | `#fafafc` | Elevated card containers and Pearl button surface |
| `text_primary` | Primary Copy | `#1d1d1f` | High contrast headings & body copy (Near-Black Ink) |
| `text_secondary` | Secondary Copy | `#333333` | Subtitles, labels & descriptions (Ink Muted 80) |
| `text_muted` | Muted Text | `#6e6e73` | Legal fine-print & captions (Ink Muted 48 - WCAG AA compliant) |
| `accent` | Accent Color | `#0066cc` | Action Blue interactive CTAs and text links |
| `slate_steel` | Steel Slate | `#475569` | Secondary borders & icon outlines |
| `border_subtle` | Subtle Border | `#e0e0e0` | Hairline card grid lines & subtle dividers |
| `border_accent` | Accent Border | `#0071e3` | Active state highlight focus borders |
